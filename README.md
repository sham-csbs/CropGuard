# Crop Guard

## Smart Crop Monitoring and Irrigation Decision System

Crop Guard is a smart farming prototype designed to help farmers monitor field conditions and make irrigation and crop-protection decisions.

## Features

- Soil moisture monitoring
- Temperature monitoring
- Humidity monitoring
- Rain forecast awareness
- Irrigation recommendation
- Water usage monitoring
- Crop protection alerts
- Pump control
- System activity log
- AI-based crop recommendation

## System Flow

Field Data → Crop Guard → Decision → Pump / Alert → Farmer

## Irrigation

The system checks soil moisture and weather conditions to recommend whether the farmer should water the crop or wait.

## Crop Protection

The prototype uses a PIR-based protection concept. When movement is detected near the field perimeter, an alert mechanism can be triggered.

## AI Recommendation

The dashboard can send current field conditions such as soil moisture, temperature, humidity and rainfall information to the crop-decision API and receive a recommendation.

## Prototype

The current dashboard includes Demo Mode to demonstrate changing sensor values and the complete workflow.

## Goal

Crop Guard converts field information into simple and useful actions for farmers.
